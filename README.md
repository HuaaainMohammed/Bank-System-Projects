# 🏦 Bank System Projects

A collection of C++ Bank System projects developed throughout my Problem Solving journey. This repository documents the evolution of the application from basic client management and file handling to financial transactions, user management, and access control.

---

## 📌 Projects

### 1️⃣ Bank System

The first version focuses on managing bank clients and storing their data using files.

**Features:**

* 👤 Add new clients
* 🗑️ Delete clients
* ✏️ Update client information
* 🔍 Find clients
* 📋 Display client list
* 💾 File handling and data persistence

---

### 2️⃣ Bank System with Transactions

An enhanced version of the Bank System introducing financial transaction functionality.

**Features:**

* 💵 Deposit
* 💸 Withdraw
* ⚡ Quick Withdraw
* 🏧 Normal Withdraw
* 💰 Check Balance
* 🔄 Update account balances
* 📊 Total balances report
* 💾 Persist transaction updates to files
* ✅ Balance validation

---

### 3️⃣ Bank System with User Management & Permissions

The third phase introduces user management, login functionality, access control, and permission handling.

**Features:**

* 🔐 **Login System:** Secure login using account credentials.
* 👥 **User Management:** Full CRUD operations for system users (List, Add, Delete, Update, Find).
* 🔑 **Permissions Structure:** Assigns specific permissions to users using Enums.
* 🛡️ **Access Control:** Checks user permissions before allowing access to specific system features.
* 🔄 **Dynamic Updates:** Updates user information, passwords, and permissions while maintaining data persistence.
* 💾 **File-Based Data Storage:** Stores users and client information in files.
